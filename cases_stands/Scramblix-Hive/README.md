Description
The Scramblix Hive is a custom-designed 3D-printed case for the Bitaxe Gamma miner.
It enhances airflow, protects the board, and provides a clean and compact enclosure—while maintaining full compatibility with stock cooling parts.

📦 Features
🛠️ No modifications required – Fits stock Bitaxe Gamma heatsink and fan
🌬️ Optimized airflow – Honeycomb mesh design maximizes cooling efficiency
🔧 Easy assembly – Includes a snap-fit tool for damage-free installation
🎨 Minimalist design – Compact and clean look to showcase your build

🔌 Compatibility
Designed for Bitaxe Gamma (tested with 1.2T board)
Fully compatible with stock heatsink and stock fan
